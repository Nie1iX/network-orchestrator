# S8 — Fedora

**Дата:** 2026-09-28 · **Статус:** реализовано. Проверено в Docker:
E2E с клиентом Fedora и Ubuntu, GUI smoke из `.rpm` и `.deb`, жизненный цикл
rpm. SELinux enforcing и desktop — у владельца. · **Основание:** владелец перешёл на Fedora как основную
систему. **Цель:** `.rpm` ставится на Fedora 44 и проходит тот же E2E, что и
Ubuntu. Ubuntu/Debian и Arch при этом не ломаются.

## Изменения

1. Daemon ставится в `/usr/bin/network-orchestrator-daemon` на всех
   дистрибутивах: unit, `.deb`, `PKGBUILD`, dev-скрипт (`/usr/local/bin`),
   E2E. `/usr/bin` допустим и в Arch, и в Debian. Xray остаётся в
   `/usr/lib/network-orchestrator/xray/`: его запускает daemon, смены домена
   нет.
2. RPM: `bundle.linux.rpm` в `tauri.conf.json` (те же файлы, что у `.deb`),
   scriptlet'ы `packaging/rpm/{post,preun,postun}` с семантикой `$1`.
   Сборка — `scripts/build-linux-deb.sh rpm`. При удалении state в
   `/var/lib/network-orchestrator` сохраняется (в rpm нет purge).
3. E2E: `E2E_DISTRO=fedora e2e/linux/run.sh` поднимает клиент на Fedora 44
   с включёнными firewalld и resolved; peer остаётся на Ubuntu.

## Проверка

Результаты (executed, 2026-09-28):

- E2E `E2E_DISTRO=fedora`: daemon 45, WireGuard 8+28, OpenVPN 10+19+4,
  Xray 4, Xray TUN 7+16, always-on — зелёный при включённом firewalld.
  Две правки стенда: в Fedora-клиенте `hosts: files myhostname dns`
  (иначе nss-resolve с search-доменами хоста разрешал `wg-server` во внешний
  хост) и пакет `which`.
- `.rpm`: права `0755`/`0644` (сборка задаёт `umask 022`: rpm-бандлер копирует
  права с диска). В `dnf install` служба включена и запущена. Обновление
  (`rpm -Uvh --replacepkgs`) перезапускает daemon. `dnf remove` снимает
  активный маршрут, удаляет unit и бинарник, state остаётся.
- GUI smoke из `.rpm` на Fedora 44 и из `.deb` на Ubuntu 26.04 зелёные.
  В тестовой установке отключён репозиторий `fedora-cisco-openh264`:
  его зеркала были недоступны, и WebKit он нужен только как слабая
  зависимость.
- Регрессия Ubuntu после переноса daemon'а в `/usr/bin`: E2E зелёный.

План проверки:

- Полный E2E с клиентом Fedora.
- `.rpm`: `rpm -qpR`/`-qpl`, установка и удаление через `dnf` в контейнере,
  GUI smoke из `.rpm`.
- Регрессия: E2E Ubuntu и GUI smoke из `.deb` после смены пути daemon'а.

## Не проверяется здесь

- SELinux в режиме enforcing: Docker на хосте с AppArmor его не даёт.
  Проверка на машине владельца: `sudo ausearch -m avc -ts recent` после
  подключения туннелей каждого типа.
- GNOME на Fedora (tray через расширение AppIndicator, keyring), suspend и
  resume, реальная смена сети под NetworkManager.
