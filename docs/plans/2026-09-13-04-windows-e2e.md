# Windows Multi-Tunnel E2E Verification Plan

**Goal:** Prove real WireGuard, OpenVPN, Xray, elevation, routing, and recovery behavior in an isolated Windows VM.

**Architecture:** Add an opt-in ignored integration harness driven by environment-provided fixture paths. Tests record before/after snapshots and always attempt cleanup; no credentials enter source control or test output.

**Tech Stack:** Rust integration tests, PowerShell setup scripts, Windows VM, Tauri packaged debug build

---

### Task 1: Define safe fixture contract

Use environment variables for fixture paths and expected private CIDRs. Require a disposable VM marker before any mutation. Abort if the marker or admin token is missing.

### Task 2: Capture baseline snapshots

Record interfaces, routes, DNS, services, OpenVPN/Xray processes, proxy settings, and listener ports before each scenario. Redact config contents and credentials.

### Task 3: Verify backend lifecycle

Run independent scenarios for WireGuard service, OpenVPN child, Xray existing JSON, and generated VLESS SOCKS. Assert connect/status/disconnect and zero owned residue.

### Task 4: Verify route composition

Scenarios:

- WireGuard `10.0.0.0/8` + OpenVPN `10.20.0.0/16` succeeds and `/16` wins.
- Exact duplicate prefix blocks the second profile.
- OpenVPN default + specific route follows LPM.
- WireGuard `/0` kill-switch blocks unsafe composition.
- IPv4 and IPv6 policy routes are added and removed.

### Task 5: Verify conflict and port behavior

Test duplicate listeners, automatic VLESS port allocation, port reallocation after external occupation, and incomplete OpenVPN pushed-route fail-closed behavior.

### Task 6: Verify lifecycle and recovery

Test normal close, elevated restart, forced termination, stale registry, missing route, remaining WireGuard service, and Job Object child termination.

### Task 7: Produce artifacts

Store redacted JSON snapshots and logs under test output, not the repository. Diff baseline/final state and fail on app-owned residue.

### Validation

```bash
cargo test --workspace
cargo test -p net-manager-app --test windows_e2e -- --ignored --nocapture
```

The ignored test runs only with explicit VM/admin/fixture environment variables.
